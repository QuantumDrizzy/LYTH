# ADR-0030 step 5 -- the protocol for Q2 and Q3

Frozen before the first launch; hashes of this file, `tools/fusion_sweep.py`,
`crates/lyth-circuit/examples/circuit_time.rs` and `crates/lyth-circuit/examples/q2_group.rs` in
`docs/prereg/ADR-0030.step5.PREREG_SHA256.txt`. The predictions are ADR-0030's Q2 and Q3, frozen in
`docs/prereg/ADR-0030.prereg-frozen.md`. This fixes what the ADR left open.

## Q2 -- a fused pass costs one pass

* Groups written by `q2_group`: `g ∈ {1, 2, 5, 10, 20, 40}` gates on qubit set `A = {7, 6, 5, 4, 3}`
  (lowest qubit 3) and on `B = {4, 3, 2, 1, 0}` (lowest qubit 0), seed 30. Each is run as one
  `lyth run` at `-n 8388608` with its widths.
* The single-gate pass: `gate_q` at `w = 2^22` (a contiguous pair, which ADR-0028 step 5 measured
  equal to the contiguous kernel at the L2), same size, the unitary `ar=0.6 ai=0.1 br=0.2 bi=0.7
  cr=0.3 ci=0.5 dr=0.6 di=0.4`.
* `ncu`, default cache control, 3 launches per configuration in shuffled rounds
  (`random.Random(305)`), median per counter, divided by the 2^23 amplitudes.
* **Verdicts:** DRAM bytes per amplitude (read + write) within 5% of the single-gate pass for every
  group of A and B; L2 bytes per amplitude at most 1.10x the single-gate pass for every group of A.
  Reported beside them, no verdict: B's L2 figure, and each group's derived intensity.

## Q3 -- time follows passes

* `circuit_time` on `circuits::random(23, 10, seed 20260930)`: modes `unfused` and `k = 1 .. 5`.
  One process per sample: modules loaded (not timed), one warm-up run discarded, 10 timed runs,
  the process median. 7 rounds, each with all six modes in an order from `random.Random(306)`.
  A mode's time is the median of its 7 process medians; its spread `(max - min) / median`.
* `G` is the gate count, `F_k` the passes at `k`. **Verdict:** `T_k / T_unfused <= 1.15 * F_k / G`
  at every `k`. Published beside it at every `k`: `F_k / G`, `T_k / T_unfused`, and the achieved
  bandwidth `16 B x 2^23 x F_k / T_k`.
* Timing includes launch overhead (first launch to last synchronize): it is what a caller pays.
